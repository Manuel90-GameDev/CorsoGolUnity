1) Crea la scena "LezioneTerrain".
2) Crea un terreno (GameObject -> 3D Object -> Terrain).
  - Piazza un cubo (0.5,0.5,0.5) per far vedere la scala del terreno.
3) Seleziona il terreno nella gerarchia e vai al pannello "Inspector".
  - Spiega rapidamente le 5 icone principali del Terrain Inspector (Neighbor Terrains, Paint Terrain, Paint Trees, Paint Details, Terrain Settings).
4) Mostra il Neighbor Terrains:
  - Spiega come collegare più terreni insieme per creare un'area più grande.
5) Passa alla modalità "Paint Terrain":
  - Set Height: Spiega come alzare o abbassare il terreno.
  - Raise/Lower Terrain: Mostra come scolpire il terreno.
  - Smooth Height: Spiega come ammorbidire le irregolarità del terreno.
  - Paint Texture: Mostra come applicare texture diverse al terreno.
    - Scarica l'asset "Handpainted Grass & Ground Textures".
    - Crea diversi layer di texture (erba, terra, roccia) e applicali al terreno.
      - Edit Terrain Layers -> Create Layer -> Seleziona la texture desiderata.
6) Passa alla modalità "Paint Trees":
  - Scarica l'asset "Mountain Terrain, Rocks and Tree" da Unity Asset Store.
  - Scarica l'asset "Free Trees" da Unity Asset Store.
    - Edit Tree Prototypes -> Add Tree -> Seleziona un albero dall'asset scaricato.
7) Passa alla modalità "Paint Details":
  - Scarica l'asset "Grass and Flowers Pack" da Unity Asset Store.
  - Mostra come dipingere l'erba e i fiori sul terreno.
    - Edit Detail Prototypes -> Add Grass Texture -> Seleziona una texture di erba dall'asset scaricato.
    - Edit Detail Prototypes -> Add Detail Mesh -> Seleziona un fiore dall'asset scaricato.
8) Passa alla modalità "Terrain Settings":
  - Spiega le impostazioni principali come la dimensione del terreno, la risoluzione delle texture, e le impostazioni di illuminazione.
9) Metti in scena il Player
10) Installa il "Terrain Tools" tramite il Package Manager per funzionalità avanzate di modellazione del terreno."
11) Scarica l'asset "Heightmap Generator" (faccio lo sborone =D)
12) Crea un terreno utilizzando una heightmap generata proceduralmente.
