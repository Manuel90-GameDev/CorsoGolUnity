##### STEP CREAZIONE GAMEMANAGER



1. Creo un Game Object vuoto nella scena chiamato "GameManager"
2. Trascino l'oggetto nella cartella "Prefab" per crearne il prefab
3. Creo lo script "GameManager.cs" da attaccare al prefab
4. Implemento Singleton e DontDestroy nello script
5. Inserito un esempio di registrazione al manager
6. Sia nello script "PlayerControllerOld" che in "PlayerControllerNew" registro il gameobject al gamemanager
